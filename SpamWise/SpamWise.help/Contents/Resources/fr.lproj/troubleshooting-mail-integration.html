Résoudre les problèmes d’intégration Mail

SpamWise n’est pas autorisé à contrôler Mail

SpamWise lit et déplace les messages par l’intermédiaire de Mail, ce qui nécessite votre autorisation. Si Réglages → Comptes indique « SpamWise n’est pas autorisé à contrôler Mail : il ne peut donc ni vérifier ni déplacer les messages » :

  1. Choisissez Ouvrir les réglages Automatisation. Vous pouvez aussi ouvrir Réglages Système → Confidentialité et sécurité → Automatisation.
  2. Sous SpamWise, activez Mail.
  3. Dans SpamWise, choisissez Vérifier la connexion à Mail.

SpamWise n’a pas besoin de l’accès complet au disque : ne l’accordez pas et ne désactivez pas les fonctions de sécurité de macOS. Si les Réglages vous demandent d’ouvrir Mail, ouvrez-le ; SpamWise vérifie vos comptes dès que Mail est ouvert.

L’accès à Contacts est facultatif. Pour l’autoriser, activez SpamWise dans Réglages Système → Confidentialité et sécurité → Contacts, puis choisissez Connecter Contacts dans Réglages → Comptes.

Un message n’a pas été déplacé

Sélectionnez le message dans Activité et regardez son Résultat dans l’inspecteur. Le menu SpamWise de la barre des menus et le bas de la fenêtre Activité indiquent aussi ce qui bloque le filtrage. Causes fréquentes :

  • La simulation est active. Le Résultat est Simulation. Choisissez Commencer le filtrage…, ou désactivez « Simulation — ne pas modifier les messages » dans Réglages → Général. SpamWise agit ensuite sur les messages vérifiés pendant la simulation qui sont toujours dans votre boîte de réception.
  • SpamWise n’a pas trouvé les boîtes de réception et d’indésirables du compte. Le compte indique « SpamWise ne déplacera pas les messages de ce compte tant qu’il n’aura pas trouvé les boîtes de réception et d’indésirables. » Choisissez Vérifier la connexion à Mail, ou ouvrez Boîtes et détails sous le compte et choisissez Vérifier les boîtes aux lettres. Consultez Configurer la boîte des indésirables du compte.
  • Le filtrage est suspendu. Le Résultat est En pause. Choisissez Filtrage → Reprendre le filtrage.
  • Le compte n’est pas inclus. Activez Filtrer ce compte sous le compte, dans Réglages → Comptes. Le filtrage commence avec les messages qui arrivent ensuite.
  • Il n’y a pas de clé API, ou le partage des messages est désactivé. Le Classement est Non classé. Dans Réglages → Fournisseur, ajoutez la clé sous Clé API et activez « Autoriser l’envoi du contexte des messages à fournisseur ». L’enregistrement de la clé relance automatiquement la vérification des messages en attente. Pour vérifier un message tout de suite, sélectionnez-le et choisissez Classer à nouveau.
  • La limite de dépenses mensuelle est atteinte. Augmentez la limite sous Utilisation et dépenses, dans Réglages → Fournisseur, ou attendez le mois suivant.
  • Le message n’a pas de Message-ID. L’inspecteur indique « Le message n’a pas de Message-ID ; SpamWise ne le déplace donc pas automatiquement et l’a laissé en place. » Vous pouvez toujours le corriger dans Activité, ou le déplacer vous-même dans Mail.
  • Le message est arrivé avant le début du filtrage. Les messages plus anciens ne sont pas triés automatiquement ; consultez Trier les messages plus anciens.
  • Mail n’est pas ouvert, ou le Mac est hors ligne. Les vérifications reprennent à l’ouverture de Mail ou au retour de la connexion.
  • Le classement est Légitime ou À vérifier. Les messages légitimes restent dans Réception, et les messages à vérifier y restent avec leur marque orange.

Configurer la boîte des indésirables du compte

SpamWise ne déplace des messages que dans les comptes pour lesquels Mail affiche exactement une boîte de réception et une boîte des indésirables. Si le compte indique que Mail n’a pas de boîte d’indésirables définie :

  1. Dans Mail, sélectionnez le dossier d’indésirables du compte dans la barre latérale. Si le compte n’en a pas, créez-en un avec Boîte aux lettres → Nouvelle boîte aux lettres, en choisissant le compte comme emplacement.
  2. Choisissez Boîte aux lettres → Utiliser cette boîte pour → Indésirables.
  3. Dans SpamWise, ouvrez Boîtes et détails sous le compte, dans Réglages → Comptes, et choisissez Vérifier les boîtes aux lettres.

Si le compte indique que Mail affiche plusieurs boîtes d’indésirables, gardez le rôle Indésirables sur un seul dossier : dans Mail, sélectionnez le dossier à utiliser, choisissez Boîte aux lettres → Utiliser cette boîte pour → Indésirables, puis choisissez Vérifier les boîtes aux lettres. Si Mail affiche toujours une autre boîte d’indésirables pour le compte, son serveur en signale peut-être plusieurs ; renseignez-vous auprès de votre fournisseur de messagerie. Avec une connexion IMAP, le serveur lui-même doit désigner un dossier comme son dossier d’indésirables ; renseignez-vous auprès de votre fournisseur de messagerie si Vérifier la connexion ne le trouve pas.

Mail a marqué ou déplacé un message lui-même

Si un message porte la marque de courrier indésirable de Mail, ou se trouve dans Indésirables sans qu’Activité montre que SpamWise l’a déplacé, c’est le filtre de courrier indésirable de Mail ou votre serveur de messagerie. Dans Vérifier les indésirables, SpamWise indique « SpamWise n’a pas placé ce message dans les indésirables. Un autre filtre ou le serveur de messagerie l’a fait. » Pour laisser SpamWise faire le tri, désactivez le filtre de Mail ; consultez Le filtre de courrier indésirable de Mail. Sortir un tel message des indésirables n’apprend rien à SpamWise ; pour autoriser son expéditeur, choisissez Marquer comme légitime et restaurer dans Vérifier les indésirables.

Restaurer un message

SpamWise ne supprime jamais de message. Tout ce qu’il a déplacé se trouve dans la boîte des indésirables du compte.

  • Dans Activité, sélectionnez le message et choisissez Filtrage → Marquer comme légitime. SpamWise le déplace dans Réception et autorise son expéditeur.
  • Ou choisissez Filtrage → Vérifier les indésirables, choisissez le compte, sélectionnez le message et choisissez Marquer comme légitime et restaurer. Consultez Vérifier les indésirables.
  • Ou remettez le message dans Réception dans Mail, ou marquez-le comme non indésirable. Une fois la simulation désactivée, SpamWise considère que vous l’avez marqué légitime lors de sa prochaine vérification de votre boîte de réception, et autorise l’expéditeur. Ce n’est pas le cas si vous sortez le message dans les 30 secondes environ qui suivent le déplacement ; consultez Sortir un message des indésirables dans Mail.

Annuler la dernière correction… restaure les règles et l’apprentissage, mais ne déplace pas les messages.

Les messages ne sont pas classés

  • « Aucune clé API pour fournisseur » : ajoutez-en une sous Clé API, dans Réglages → Fournisseur.
  • Apple sur l’appareil nécessite Apple Intelligence. Activez-le dans Réglages Système → Apple Intelligence et Siri, ou choisissez un autre fournisseur.
  • « Les messages ne sont pas classés tant que le filtrage reste sur ce Mac avec un fournisseur en ligne sélectionné » : choisissez Apple sur l’appareil comme Fournisseur, ou désactivez Garder le filtrage sur ce Mac.
  • Si le fournisseur est saturé, injoignable ou trop lent, les messages restent où ils sont. Sélectionnez-en un et choisissez Classer à nouveau plus tard. SpamWise ne change jamais de fournisseur de lui-même.

Certains messages n’ont pas pu être vérifiés

Si Activité ou le menu de la barre des menus indique « Certains messages n’ont pas pu être vérifiés — voir Réglages → Comptes », l’État de chaque compte dans Réglages → Comptes montre le problème. Un message que Mail ne peut pas charger reste où il est et est réessayé plus tard, et SpamWise continue de vérifier les messages suivants. Laissez SpamWise et Mail ouverts.

Vérifier plus tôt les nouveaux messages

SpamWise vérifie votre boîte de réception toutes les minutes. Pour vérifier les nouveaux messages dès leur arrivée, ajoutez une règle Mail qui exécute le script SpamWise :

  1. Dans Réglages → Comptes, sous Nouveaux messages, choisissez Afficher le script dans le Finder.
  2. Copiez le script sélectionné dans le dossier ~/Library/Application Scripts/com.apple.mail. Pour ouvrir ce dossier, choisissez Aller → Aller au dossier dans le Finder.
  3. Dans Mail, choisissez Mail → Réglages, cliquez sur Règles, puis sur Ajouter une règle. Réglez la condition sur Tous les messages et l’action sur Exécuter un AppleScript, puis choisissez le script SpamWise.

La règle vérifie les nouveaux messages en arrière-plan, sans mettre SpamWise au premier plan. Il n’est pas nécessaire d’activer SpamWise dans les réglages d’extensions de Mail.
