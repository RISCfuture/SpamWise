Premiers pas

SpamWise trie les messages qui arrivent dans Apple Mail. Les messages légitimes restent dans Réception. Les messages à vérifier restent dans Réception avec un drapeau ou un fond orange, pour que vous puissiez les examiner. Les indésirables sont déplacés dans la boîte des indésirables du compte. SpamWise ne supprime jamais de message et n’en place jamais dans la Corbeille.

Configurer SpamWise

À la première ouverture, SpamWise vous guide en cinq étapes.

  1. Lisez comment SpamWise traite vos données personnelles, puis choisissez Continuer.
  2. Choisissez un Fournisseur, qui classe les messages que vos règles et les expéditeurs connus ne décident pas :
    • Apple sur l’appareil classe les messages sur ce Mac avec Apple Intelligence. Les messages ne sont envoyés nulle part, sans clé API ni frais.
    • Claude, OpenAI et Gemini classent les messages avec votre propre clé API, et chaque message est facturé sur le compte de votre fournisseur. Une clé API est un long code, comme un mot de passe, qui permet à SpamWise d’utiliser le fournisseur avec votre compte. Choisissez Obtenir une clé API pour en créer une sur le site web du fournisseur, puis copiez-la et collez-la dans SpamWise. Choisissez Vérifier et enregistrer la clé ou Enregistrer la clé, puis activez « Autoriser l’envoi du contexte des messages à fournisseur ».
    Pour décider plus tard, choisissez Ignorer pour l’instant ; vous pourrez choisir un fournisseur à tout moment dans Réglages → Fournisseur.
  3. Choisissez Vérifier la connexion à Mail et autorisez SpamWise à contrôler Mail lorsque macOS le demande. SpamWise trouve les boîtes de réception et d’indésirables de chaque compte sans modifier vos messages. Pour qu’il reconnaisse les personnes que vous connaissez, choisissez Connecter Contacts et Importer l’historique de Réception et d’Envoyés. Si vous utilisez plutôt une connexion IMAP, cette étape affiche ses réglages ; consultez Se connecter en IMAP.
  4. Choisissez quoi faire de chaque type de message dont vous ne voulez peut-être pas, comme les promotions de boutiques ou les infolettres : Garder, Signaler ou Indésirables. Pour donner à SpamWise des exemples de ce dont vous ne voulez pas, choisissez Analyser les dossiers d’indésirables, puis Enregistrer les exemples. Consultez Choisir les messages que vous voulez recevoir.
  5. Choisissez Simuler sur les messages récents pour voir ce que SpamWise ferait de vos 20 messages les plus récents de Réception. Rien ne change dans Mail. Choisissez ensuite Terminer la configuration.

Pour refaire ces étapes, choisissez Afficher la configuration initiale dans Réglages → Général.

Le filtre de courrier indésirable de Mail

Mail a son propre filtre de courrier indésirable, actif sauf si vous l’avez désactivé. Il fonctionne indépendamment de SpamWise : il peut marquer des messages de Réception comme indésirables, ce qui ne ressemble pas à la marque orange À vérifier de SpamWise, ou déplacer lui-même des messages dans Indésirables. Pour laisser SpamWise faire le tri :

  1. Dans Mail, choisissez Mail → Réglages, puis cliquez sur Courrier indésirable.
  2. Désactivez « Activer le filtrage du courrier indésirable ».

Si vous gardez le filtre de Mail actif, ses marques et ses déplacements ne viennent pas de SpamWise. Activité ne liste que ce que SpamWise a décidé, et Vérifier les indésirables indique quels messages SpamWise a déplacés.

Commencer le filtrage

La simulation reste active après la configuration : Activité montre ce que SpamWise ferait, et vos messages restent où ils sont. Quand les décisions vous conviennent, choisissez Commencer le filtrage…, puis Désactiver la simulation. Commencer le filtrage… se trouve en bas de la fenêtre Activité, dans le menu Filtrage et dans le menu SpamWise de la barre des menus. Vous pouvez aussi désactiver « Simulation — ne pas modifier les messages » dans Réglages → Général.

Le filtrage réel nécessite les boîtes de réception et d’indésirables d’au moins un compte, et seuls ces comptes sont filtrés. Tant que SpamWise ne les a pas trouvées, ces emplacements proposent à la place Vérifier la connexion à Mail…, ou Vérifier la connexion… en IMAP, qui ouvre Réglages → Général. SpamWise vérifie chaque déplacement après coup. Si Mail ne confirme pas un déplacement, SpamWise ne le refait pas et ne l’annule pas, et Activité affiche l’échec pour que vous puissiez vérifier le message dans Mail.

Tant que la simulation reste active, SpamWise vérifie chaque message une seule fois, même si vous modifiez ensuite vos règles ou vos réglages de filtrage, ou corrigez un message. Quand vous désactivez la simulation, SpamWise agit aussi sur les messages vérifiés pendant la simulation qui sont toujours dans votre boîte de réception. Si vos règles, vos réglages de filtrage et la clé API du fournisseur utilisé n’ont pas changé depuis, il réutilise ces décisions au lieu de renvoyer les messages à votre fournisseur. Avec une connexion IMAP, les messages vérifiés pendant la simulation restent où ils sont.

Laisser SpamWise ouvert

SpamWise vérifie la boîte de réception de chaque compte toutes les minutes tant que SpamWise et Mail sont ouverts. Si vous fermez ses fenêtres, SpamWise reste actif ; si vous le quittez, le filtrage s’arrête. Tant qu’il est actif, son élément de la barre des menus indique s’il filtre : un bouclier pendant le filtrage, une enveloppe tant que les messages restent inchangés, un symbole de pause quand il est suspendu et un symbole d’avertissement quand quelque chose demande votre attention. Si vous désactivez Afficher SpamWise dans la barre des menus dans Réglages → Général, cliquez sur SpamWise dans le Dock pour ouvrir Activité. Pour que SpamWise s’ouvre automatiquement, activez Ouvrir SpamWise à l’ouverture de session dans Réglages → Général. Pour vérifier les nouveaux messages dès leur arrivée, consultez Vérifier plus tôt les nouveaux messages.

Trier les messages plus anciens

Le filtrage automatique porte sur les messages qui arrivent après la configuration, ou après l’ajout d’un compte. Pour trier les messages déjà présents dans Réception avec Apple Mail :

  1. Désactivez la simulation.
  2. Dans Réglages → Comptes, ouvrez Messages plus anciens sous le compte.
  3. Choisissez Aperçu des anciens messages de Réception, puis vérifiez les décisions dans Activité.
  4. Choisissez Appliquer nombre décisions…. SpamWise indique combien de messages seront déplacés dans Indésirables, marqués À vérifier ou laissés dans Réception ; choisissez Appliquer les décisions. Pour continuer, augmentez la page de messages antérieurs et prévisualisez la page suivante.

Les aperçus envoient des messages à votre fournisseur, ce qui peut être payant. Modifier les réglages supprime les aperçus que vous n’avez pas appliqués.
