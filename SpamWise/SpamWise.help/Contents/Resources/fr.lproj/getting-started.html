Premiers pas

SpamWise trie les messages qui arrivent dans Apple Mail. Les messages légitimes restent dans Réception. Les messages à vérifier restent dans Réception avec un drapeau ou un fond orange, pour que vous puissiez les examiner. Les indésirables sont déplacés dans la boîte des indésirables du compte. SpamWise ne supprime jamais de message et n’en place jamais dans la Corbeille.

Configurer SpamWise

À la première ouverture, SpamWise vous guide en quatre étapes.

  1. Lisez comment SpamWise traite vos données personnelles, puis choisissez Continuer.
  2. Choisissez un Fournisseur, qui classe les messages que vos règles et les expéditeurs connus ne décident pas :
    • Apple sur l’appareil classe les messages sur ce Mac avec Apple Intelligence. Les messages ne sont envoyés nulle part, sans clé API ni frais.
    • Claude, OpenAI et Gemini classent les messages avec votre propre clé API, et chaque message est facturé sur le compte de votre fournisseur. Saisissez la clé, choisissez Vérifier et enregistrer la clé ou Enregistrer la clé, puis activez « Autoriser l’envoi du contexte des messages à fournisseur ».
    Pour décider plus tard, choisissez Ignorer pour l’instant ; vous pourrez choisir un fournisseur à tout moment dans Réglages → Classificateur.
  3. Choisissez Vérifier la connexion à Mail et autorisez SpamWise à contrôler Mail lorsque macOS le demande. SpamWise trouve les boîtes de réception et d’indésirables de chaque compte sans modifier vos messages. Pour qu’il reconnaisse les personnes que vous connaissez, choisissez Connecter Contacts et Importer l’historique de Réception et d’Envoyés.
  4. Choisissez Simuler sur les messages récents pour voir ce que SpamWise ferait de vos 20 messages les plus récents de Réception. Rien ne change dans Mail. Choisissez ensuite Terminer la configuration.

Pour refaire ces étapes, choisissez Afficher la configuration initiale dans Réglages → Général.

Commencer le filtrage

La simulation reste active après la configuration : Activité montre ce que SpamWise ferait, et vos messages restent où ils sont. Quand les décisions vous conviennent :

  1. Choisissez SpamWise → Réglages, puis Général.
  2. Désactivez « Simulation — ne pas modifier les messages », puis choisissez Désactiver la simulation.

Ce réglage devient disponible dès que SpamWise a trouvé les boîtes de réception et d’indésirables d’au moins un compte, et seuls ces comptes sont filtrés. SpamWise vérifie chaque déplacement après coup. Si Mail ne confirme pas un déplacement, SpamWise ne le refait pas et ne l’annule pas, et Activité affiche l’échec pour que vous puissiez vérifier le message dans Mail.

Les messages vérifiés pendant une simulation conservent leur décision. Pour déplacer l’un d’eux, corrigez-le dans Activité.

Laisser SpamWise ouvert

SpamWise vérifie la boîte de réception de chaque compte toutes les minutes tant que SpamWise et Mail sont ouverts. Si vous fermez ses fenêtres, SpamWise reste actif dans la barre des menus ; si vous le quittez, le filtrage s’arrête. Pour qu’il s’ouvre automatiquement, activez Ouvrir SpamWise à l’ouverture de session dans Réglages → Général. Pour vérifier les nouveaux messages dès leur arrivée, consultez Vérifier plus tôt les nouveaux messages.

Trier les messages plus anciens

Le filtrage automatique porte sur les messages qui arrivent après la configuration, ou après l’ajout d’un compte. Pour trier les messages déjà présents dans Réception :

  1. Désactivez la simulation.
  2. Dans Réglages → Comptes, ouvrez Messages plus anciens sous le compte.
  3. Choisissez Aperçu des messages antérieurs de Réception, puis vérifiez les décisions dans Activité.
  4. Choisissez Appliquer les décisions prévisualisées. Pour continuer, augmentez la page de messages antérieurs et prévisualisez la page suivante.

Les aperçus envoient des messages à votre fournisseur, ce qui peut être payant. Modifier les réglages supprime les aperçus que vous n’avez pas appliqués.
