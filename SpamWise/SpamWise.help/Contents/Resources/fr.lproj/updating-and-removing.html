Mettre à jour et désinstaller SpamWise

Ne gardez qu’une seule copie de SpamWise sur votre Mac. La version de l’App Store et la version téléchargée partagent leurs réglages : installez l’une ou l’autre.

Mettre à jour SpamWise

Si vous avez obtenu SpamWise sur l’App Store, il se met à jour par l’App Store comme vos autres apps.

Si vous avez téléchargé SpamWise, il recherche lui-même les nouvelles versions. Dans Réglages → Général, sous Mises à jour de l’application :

  • Rechercher des mises à jour fixe la fréquence de recherche : Toutes les heures, Tous les jours, Toutes les semaines ou Jamais.
  • Inclure les versions préliminaires propose aussi des versions de test avant leur sortie.
  • Vérifier maintenant recherche tout de suite, comme SpamWise → Rechercher des mises à jour…. Réinitialiser les versions ignorées propose de nouveau les versions que vous avez choisi d’ignorer.

Quand vous acceptez une mise à jour, SpamWise la télécharge sous forme d’image disque. Avant de l’installer, vous pouvez exporter une sauvegarde ; consultez Exporter une sauvegarde. Quittez ensuite SpamWise, ouvrez l’image disque, faites glisser SpamWise dans le dossier Applications pour remplacer l’ancienne copie, puis rouvrez SpamWise. Vos réglages, vos règles et l’apprentissage restent tels quels.

Empêcher SpamWise de s’ouvrir à l’ouverture de session

Désactivez Ouvrir SpamWise à l’ouverture de session dans Réglages → Général. Vous pouvez aussi vérifier les éléments d’ouverture dans Réglages Système → Général. SpamWise ne filtre que lorsqu’il est ouvert : pour arrêter le filtrage tout de suite, choisissez Quitter SpamWise dans son menu de la barre des menus ou SpamWise → Quitter SpamWise.

Supprimer les clés et mots de passe

SpamWise conserve vos clés API, la clé de requête Spamhaus et votre mot de passe IMAP dans le trousseau. Supprimer l’app seule les y laisse : supprimez-les d’abord si vous n’utiliserez plus SpamWise. Dans Réglages → Comptes, sous Clés et mots de passe :

  • Pour en supprimer un, choisissez Supprimer à côté. Pour supprimer la clé API d’un fournisseur, vous pouvez aussi choisir Supprimer la clé… dans Réglages → Fournisseur.
  • Pour tout supprimer, choisissez Supprimer toutes les clés et tous les mots de passe de SpamWise…, puis Tout supprimer.

Les messages ne sont plus classés avec un fournisseur tant que vous n’avez pas ajouté de nouveau sa clé. Pour ne plus utiliser une connexion IMAP, consultez Se connecter en IMAP.

Retirer SpamWise de votre Mac

  1. Supprimez vos clés et mots de passe, comme indiqué ci-dessus, et désactivez Ouvrir SpamWise à l’ouverture de session.
  2. Si vous avez ajouté la règle Mail qui exécute le script SpamWise, ouvrez Mail → Réglages, cliquez sur Règles, sélectionnez la règle et cliquez sur Supprimer. Retirez ensuite le script SpamWise du dossier ~/Library/Application Scripts/com.apple.mail.
  3. Quittez SpamWise, puis faites-le glisser du dossier Applications vers la Corbeille.

Retirer SpamWise ne modifie pas vos messages. Les messages qu’il a déplacés dans Indésirables y restent, et les marques À vérifier restent jusqu’à ce que vous les retiriez dans Mail. Vos règles, vos corrections et l’apprentissage restent sur ce Mac et sont donc de retour si vous réinstallez SpamWise.

Pour supprimer aussi ces données, exportez d’abord une sauvegarde si vous pourriez en avoir besoin plus tard. Ensuite, dans le Finder, choisissez Aller → Aller au dossier et ouvrez ~/Library/Group Containers. Placez le dossier group.codes.tim.SpamWise dans la Corbeille. Ouvrez ensuite ~/Library/Containers et placez les dossiers codes.tim.SpamWise et codes.tim.SpamWise.MailExtension dans la Corbeille ; le Finder peut les afficher sous le nom SpamWise. Ne supprimez pas les dossiers de Mail.
