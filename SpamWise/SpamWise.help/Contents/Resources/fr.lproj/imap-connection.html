Se connecter en IMAP

SpamWise fonctionne habituellement par l’intermédiaire d’Apple Mail. Il peut aussi se connecter directement à un compte IMAP par une connexion sécurisée.

  1. Dans Réglages → Comptes, sous Connexion de messagerie, réglez Connexion sur IMAP, puis choisissez Passer à IMAP. La simulation s’active.
  2. Sous Compte IMAP, saisissez le Serveur, votre Nom d’utilisateur et votre Mot de passe. Si votre fournisseur utilise un autre port, ouvrez Options de connexion pour changer le Port TLS.
  3. Choisissez Enregistrer la connexion. Le mot de passe est enregistré dans le trousseau.
  4. Choisissez Vérifier la connexion. SpamWise se connecte, trouve les boîtes de réception et d’indésirables et lit les messages sans les modifier.
  5. Lorsque vous êtes prêt, désactivez la simulation dans Réglages → Général.

Le serveur doit permettre de déplacer des messages et identifier sa boîte des indésirables ; sinon, SpamWise laisse les messages inchangés. Si vous remettez dans Réception, avec une autre app de messagerie, un message que SpamWise avait placé dans Indésirables, SpamWise le considère comme marqué légitime.

Pour ne plus utiliser IMAP, choisissez Oublier la connexion…. SpamWise supprime le mot de passe du trousseau et revient à Apple Mail avec la simulation activée. Les messages sur le serveur restent tels quels.
