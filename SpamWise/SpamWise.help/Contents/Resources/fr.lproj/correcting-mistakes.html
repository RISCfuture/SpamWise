Corriger les erreurs

Corriger un message dans Activité

Sélectionnez le message dans Activité, puis choisissez l’une de ces commandes dans le menu Filtrage, ou cliquez sur le message en maintenant la touche Contrôle enfoncée :

  • Marquer comme légitime (Option + Commande + G) déplace le message dans Réception.
  • Marquer comme indésirable (Option + Commande + J) le déplace dans la boîte des indésirables du compte.
  • Marquer pour vérification (Option + Commande + R) le remet dans Réception avec la marque À vérifier.

Vous pouvez aussi utiliser les boutons Légitime, Indésirables et À vérifier sous Corriger cette décision, dans l’inspecteur. SpamWise enregistre d’abord votre correction, puis demande à Mail de déplacer le message. Si le déplacement échoue, la correction reste enregistrée et le Résultat de l’inspecteur indique ce qui s’est passé dans Mail. Un message sans adresse d’expéditeur ne peut pas être corrigé ; déplacez-le dans Mail.

Ce que retient une correction

  • Marquer comme légitime crée une règle Autoriser pour l’adresse de l’expéditeur, et Marquer comme indésirable une règle Bloquer. Une nouvelle correction remplace la règle précédente pour cette adresse.
  • Marquer pour vérification supprime la règle de l’adresse de l’expéditeur. Une règle portant sur le domaine de l’expéditeur reste en vigueur.
  • Chaque correction est aussi conservée comme exemple pour votre fournisseur et pour l’apprentissage. Consultez Messages vérifiés et apprentissage.

Si SpamWise n’a pas pu vérifier qu’un message vient vraiment de son expéditeur, il demande confirmation avant de bloquer, car bloquer une adresse falsifiée envoie aussi dans Indésirables les messages du véritable expéditeur. Choisissez Bloquer l’expéditeur quand même, Signaler comme arnaque pour déplacer le message dans Indésirables sans créer de règle pour l’expéditeur, ou Annuler. Si une règle de domaine continue de décider des messages de l’expéditeur à l’encontre de votre correction, SpamWise vous le signale ; choisissez Conserver la règle ou Supprimer la règle.

Si le message appartient à un type de courrier que vous pouvez régler dans Choix de courrier, comme une promotion de boutique, SpamWise peut vous demander s’il faut faire de même pour tout ce type. Choisissez Cet expéditeur seulement, ou Tout garder dans Réception, Tout signaler À vérifier ou Tout déplacer dans Indésirables.

Corriger tout un domaine

Pour autoriser ou bloquer tous les expéditeurs d’un domaine, choisissez Corriger tout le domaine… dans l’inspecteur, puis Autoriser ce domaine ou Bloquer ce domaine. Pour les domaines partagés par de nombreuses personnes, comme les grands fournisseurs de messagerie, SpamWise demande d’abord confirmation, car la règle s’appliquerait aussi à des personnes sans rapport entre elles. Une règle pour une adresse l’emporte toujours sur une règle pour son domaine.

Corriger les messages sélectionnés dans Mail

Sélectionnez un ou plusieurs messages dans Mail. Ensuite, dans le menu SpamWise de la barre des menus, sous Messages sélectionnés dans Mail, choisissez Marquer comme légitime, Marquer comme indésirable ou Marquer pour vérification, ou choisissez Corriger les domaines des expéditeurs → Autoriser les domaines des expéditeurs ou Bloquer les domaines des expéditeurs. Le menu affiche la progression ; choisissez Afficher les résultats de la correction… pour le détail. Si certains expéditeurs ne peuvent pas être vérifiés, choisissez Confirmer les expéditeurs non vérifiés…, puis Tout bloquer ou Ignorer les expéditeurs non vérifiés. Ces corrections retirent aussi la marque orange À vérifier de SpamWise.

Les commandes de la barre des menus n’ont pas de raccourci clavier. Pour corriger avec une touche le message sélectionné dans Mail :

  1. Ouvrez l’app Raccourcis et créez un raccourci.
  2. Ajoutez l’action Corriger le message sélectionné de SpamWise et réglez son Étiquette sur Légitime, Indésirables ou À vérifier.
  3. Ouvrez Détails du raccourci, choisissez Ajouter un raccourci clavier, puis appuyez sur les touches voulues, par exemple Contrôle + Option + J.

Créez un raccourci pour chaque étiquette que vous utilisez. Les touches fonctionnent dans toutes les apps, y compris Mail, et corrigent le message sélectionné dans Mail.

Sortir un message des indésirables dans Mail

Si SpamWise a déplacé un message dans Indésirables et que vous le remettez dans Réception dans Mail, ou le marquez comme non indésirable, SpamWise le considère comme marqué légitime lors de sa prochaine vérification de votre boîte de réception : il autorise l’expéditeur et apprend du message. Cela fonctionne de la même façon avec une connexion IMAP et n’importe quelle app de messagerie. Ce n’est pas le cas :

  • pendant une simulation ;
  • si vous sortez le message des indésirables dans les 30 secondes environ qui suivent le déplacement. SpamWise vérifie à nouveau chaque déplacement vers Indésirables environ 30 secondes plus tard et n’apprend que des déplacements toujours en place. Si SpamWise a été quitté avant cette vérification, il n’apprend rien de ce message ;
  • pour les messages que SpamWise n’a pas placés dans Indésirables, ou que vous avez déjà corrigés.

Cette correction ne déplace jamais de message. Si vous avez de nouveau déplacé le message au moment où SpamWise le vérifie, il reste où vous l’avez mis, et Activité indique que l’action de la correction sur le message n’a pas eu lieu.

Annuler une correction

Pour annuler les règles et l’apprentissage de votre dernière correction, sélectionnez ce message et choisissez Annuler la dernière correction… dans l’inspecteur, puis Annuler les règles et l’apprentissage. Le message n’est pas déplacé : déplacez-le vous-même si nécessaire. L’annulation n’est plus possible après d’autres modifications, y compris l’enregistrement de la clé API du fournisseur utilisé.

Classer un message à nouveau

Si un message n’a pas été classé, par exemple parce que votre fournisseur était indisponible, sélectionnez-le et choisissez Filtrage → Classer à nouveau, ou Classer à nouveau dans l’inspecteur. La simulation et la pause s’appliquent toujours.
