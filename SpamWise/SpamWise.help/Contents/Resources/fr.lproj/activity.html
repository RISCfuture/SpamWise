Utiliser Activité

La fenêtre Activité liste tous les messages que SpamWise a vérifiés. Ouvrez-la avec Afficher l’activité dans le menu SpamWise de la barre des menus.

Colonnes

  • Date : quand SpamWise a décidé.
  • Expéditeur et Objet.
  • Classement : Légitime, À vérifier, Indésirables, ou Non classé si le message n’a pas pu être classé.
  • Confiance : le niveau de confiance de la décision.
  • Motif : pourquoi SpamWise a décidé ainsi, par exemple une règle, une personne que vous connaissez ou l’explication du fournisseur.

Cliquez sur l’en-tête d’une colonne pour trier selon celle-ci. Choisissez Afficher plus, en bas, pour voir des décisions plus anciennes.

Retrouver un message

Saisissez du texte dans le champ de recherche pour chercher parmi les expéditeurs, les objets et les motifs. Pour restreindre la liste, choisissez Filtrer dans la barre d’outils, puis un Compte, une source sous Décidé par, un Résultat, Corrections uniquement, Aujourd’hui uniquement ou une Plage de dates…. Choisissez Effacer les filtres pour tout revoir.

Voir les détails

Sélectionnez un message et choisissez Présentation → Afficher l’inspecteur (Option + Commande + I). L’inspecteur affiche le classement, le motif et le Résultat, c’est-à-dire ce qui s’est passé dans Mail, par exemple Appliquée, Simulation, En pause ou Échec. Il propose aussi les commandes pour corriger la décision, Aperçu du message, Ouvrir dans Mail et Exporter la source brute…. Détails de la décision indique ce qui a décidé du message, son compte et sa boîte aux lettres, l’action prévue, les jetons utilisés et le coût estimé.

Barre d’outils et menu Filtrage

  • Suspendre le filtrage arrête le tri des nouveaux messages jusqu’à ce que vous choisissiez Reprendre le filtrage. Les messages déjà triés restent où ils sont.
  • Simuler sur les messages récents montre comment SpamWise trierait vos messages les plus récents. Rien n’est déplacé.
  • Récapitulatif des messages à vérifier liste les messages de la semaine classés À vérifier. Consultez le récapitulatif des messages à vérifier.
  • Vérifier les indésirables permet de parcourir les indésirables et de restaurer ce qui n’en est pas. Consultez Vérifier les indésirables.
  • Statistiques, également dans le menu Présentation, montre combien de messages SpamWise a triés. Consultez Statistiques.

Le menu Filtrage propose aussi les commandes de correction et Classer à nouveau ; consultez Corriger les erreurs. Outils → Historique de configuration liste les modifications de vos règles, de votre politique et de l’apprentissage.

État

Le bas de la fenêtre et le menu SpamWise de la barre des menus indiquent ce que fait SpamWise, par exemple « Simulation — les messages restent inchangés », « Filtrage en pause » ou « Hors ligne — les vérifications reprennent dès le retour de la connexion ». Le bas de la fenêtre affiche aussi les chiffres du jour et le coût estimé du mois. Si quelque chose demande votre attention, consultez Résoudre les problèmes d’intégration Mail.
