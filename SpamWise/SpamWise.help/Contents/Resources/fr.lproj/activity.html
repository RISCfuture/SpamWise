Utiliser Activité

La fenêtre Activité liste les 5 000 décisions les plus récentes de SpamWise. Ouvrez-la avec Afficher l’activité dans le menu SpamWise de la barre des menus, ou cliquez sur SpamWise dans le Dock.

Colonnes

  • Date : quand SpamWise a décidé.
  • Expéditeur et Objet.
  • Classement : Légitime, À vérifier, Indésirables, ou Non classé si le message n’a pas pu être classé. Si vous avez corrigé une décision, le Classement affiche votre choix avec une marque qui indique ce que SpamWise avait décidé.
  • Confiance : le niveau de confiance de la décision.
  • Motif : pourquoi SpamWise a décidé ainsi, par exemple une règle, une personne que vous connaissez ou l’explication du fournisseur.

Cliquez sur Date, Expéditeur ou Objet pour trier selon cette colonne. Choisissez Afficher plus, en bas, pour voir des décisions plus anciennes. Double-cliquez sur un message pour l’ouvrir dans Mail, ou pour en afficher un aperçu si Mail ne peut pas l’ouvrir. Cliquez sur un message en maintenant la touche Contrôle enfoncée pour accéder à ses corrections et à d’autres commandes.

Retrouver un message

Saisissez du texte dans le champ de recherche pour chercher parmi les expéditeurs, les objets et les motifs. Pour restreindre la liste, choisissez Filtrer dans la barre d’outils, puis un Compte, une source sous Décidé par, un Résultat, Corrections uniquement, Aujourd’hui uniquement ou Plage de dates…. Choisissez Effacer les filtres pour tout revoir.

Voir les détails

Sélectionnez un message et choisissez Présentation → Afficher l’inspecteur (Option + Commande + I). L’inspecteur affiche le classement, le motif et le Résultat, c’est-à-dire ce qui s’est passé dans Mail, par exemple Appliquée, Simulation, En pause ou Échec. Il propose aussi les commandes pour corriger la décision, Aperçu du message, Ouvrir dans Mail pour les messages que Mail peut ouvrir, et Exporter la source brute…, qui enregistre le message comme fichier e-mail. Détails de la décision indique ce qui a décidé du message, son compte et sa boîte aux lettres, l’action prévue, les indices, les jetons utilisés et le coût estimé.

Barre d’outils et menu Filtrage

  • Suspendre le filtrage arrête le tri des nouveaux messages jusqu’à ce que vous choisissiez Reprendre le filtrage. Les messages déjà triés restent où ils sont.
  • Simuler sur les messages récents montre comment SpamWise trierait vos messages les plus récents. Rien n’est déplacé.
  • Récapitulatif des messages à vérifier liste les messages de la semaine classés À vérifier. Consultez le récapitulatif des messages à vérifier.
  • Vérifier les indésirables permet de parcourir les indésirables et de restaurer ce qui n’en est pas. Consultez Vérifier les indésirables.
  • Statistiques, également dans le menu Présentation, montre combien de messages SpamWise a triés. Consultez Statistiques.

Le menu Filtrage propose aussi Commencer le filtrage… pendant une simulation, les commandes de correction et Classer à nouveau ; consultez Corriger les erreurs. Outils → Historique de configuration liste les modifications de vos règles, de vos réglages et de l’apprentissage.

État

Le bas de la fenêtre et le menu SpamWise de la barre des menus indiquent ce que fait SpamWise, par exemple « Filtrage activé », « Simulation — les messages restent inchangés », « Filtrage en pause » ou « Hors ligne — les vérifications reprennent dès le retour de la connexion ». Pendant une simulation, choisissez-y Commencer le filtrage… pour que SpamWise commence à déplacer les messages ; consultez Commencer le filtrage. Le bas de la fenêtre affiche aussi les chiffres du jour et, avec Claude, OpenAI et Gemini, le coût estimé du mois. Si quelque chose demande votre attention, consultez Résoudre les problèmes d’intégration Mail.
