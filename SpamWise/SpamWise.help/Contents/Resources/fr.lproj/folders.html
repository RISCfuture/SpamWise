Dossiers

En plus de la boîte de réception de chaque compte, SpamWise peut filtrer d’autres dossiers et apprendre de dossiers que vous remplissez vous-même. Dans Réglages → Comptes, sous Dossiers, choisissez Configurer les dossiers….

Filtrer un autre dossier

  1. Choisissez le dossier dans le menu Dossier. S’il n’y figure pas, choisissez Actualiser les dossiers.
  2. Réglez Usage sur Filtrer les nouveaux messages et choisissez une date pour Filtrer les messages reçus à partir du.
  3. Activez Traiter ce dossier automatiquement, puis choisissez Enregistrer la configuration.

Pour voir d’abord ce que SpamWise déciderait, choisissez Prévisualiser cette page. Un aperçu vérifie 20 messages à la fois sans rien déplacer ; changez la page d’aperçu pour voir les messages suivants.

Enseigner à SpamWise avec des dossiers d’apprentissage

  1. Dans Mail, créez dans le compte un dossier vide nommé SpamWise Train Good ou SpamWise Train Junk.
  2. Dans Configurer les dossiers…, choisissez ce dossier et réglez Usage sur Apprendre « légitime » des messages placés ou Apprendre « indésirable » des messages placés.
  3. Choisissez Enregistrer la configuration.

Les messages que vous placez ensuite dans ce dossier comptent comme vos corrections. Gardez les dossiers d’apprentissage séparés de votre boîte des indésirables et des filtres du serveur.

Configurations enregistrées

Configurations enregistrées liste tous les dossiers que SpamWise filtre ou dont il apprend. Utilisez le commutateur d’une configuration pour cesser de traiter le dossier, ou choisissez Supprimer… pour supprimer la configuration ; le dossier et ses messages restent tels quels. Si vous renommez ou supprimez un dossier dans Mail, SpamWise cesse de le traiter et vous le signale.
