Règles d’expéditeur et de contenu

Ouvrez Réglages → Règles, puis choisissez Règles d’expéditeur ou Règles de contenu en haut.

Règles d’expéditeur

Une règle d’expéditeur autorise ou bloque toujours les messages d’une adresse ou de tout un domaine. Vos corrections créent des règles d’expéditeur ; vous pouvez aussi les gérer vous-même.

  • Pour en ajouter une, choisissez Ajouter une règle…, choisissez à quoi elle S’applique (Adresse e-mail ou Tout le domaine), saisissez l’adresse ou le domaine, choisissez Autoriser ou Bloquer, puis Enregistrer.
  • Pour changer l’action d’une règle, sélectionnez-la et choisissez Modifier…. Pour supprimer des règles, sélectionnez-les et choisissez Supprimer…. Les messages déjà filtrés restent où ils sont.
  • Pour copier vos règles sur un autre Mac, choisissez Transférer les règles → Exporter les règles…, puis Importer des règles… sur l’autre Mac. Les règles importées remplacent celles de la même adresse ou du même domaine. Les exports ne contiennent ni messages ni mots de passe.

Une règle pour une adresse l’emporte sur une règle pour son domaine. Les règles Autoriser ne décident que des messages que SpamWise peut vérifier ; consultez Faire confiance au serveur de messagerie d’un compte.

Lorsque vous corrigez de la même façon plusieurs expéditeurs d’un domaine, Réglages → Avancé propose une règle sous Règles de domaine suggérées. Choisissez Autoriser le domaine ou Bloquer le domaine pour l’ajouter.

Règles de contenu

Une règle de contenu autorise ou bloque les messages selon ce qu’ils contiennent. Les règles de contenu s’appliquent après les règles d’expéditeur.

  1. Sous Règles de contenu, choisissez Ajouter une règle….
  2. Choisissez le Champ à vérifier : Objet, Corps, List-ID, Destinataires, Reply-To, Type de contenu, Noms des pièces jointes ou Types des pièces jointes.
  3. Choisissez le type de Correspondance : Contient, Est égal à ou Expression régulière, et saisissez l’Expression. La casse n’est pas prise en compte.
  4. Choisissez Autoriser ou Bloquer, et ajoutez des Notes pour vous rappeler pourquoi.
  5. Pour essayer la règle, sélectionnez un message dans Mail et choisissez Tester avec le message sélectionné dans Mail.
  6. Choisissez Enregistrer.

Si plusieurs règles de contenu correspondent, la plus récente décide. Utilisez le commutateur d’une règle pour la désactiver sans la supprimer. Correspondances compte les messages décidés par chaque règle. Ignorées compte les messages qu’une règle n’a pas pu vérifier ; une règle trop longue à vérifier ne correspond pas. Pour copier les règles de contenu sur un autre Mac, utilisez Transférer les règles → Exporter les règles de contenu… et Importer des règles de contenu….
