Raccourcis

SpamWise ajoute ces actions à l’app Raccourcis :

  • Aperçu du message sélectionné classe le message sélectionné dans Mail sans le déplacer. Elle utilise votre fournisseur et votre limite de dépenses.
  • Corriger le message sélectionné corrige le message sélectionné dans Mail en Légitime, Indésirables ou À vérifier, comme les commandes d’Activité. La pause, la simulation et la vérification des boîtes du compte s’appliquent toujours.
  • Obtenir l’état de SpamWise renvoie l’état de SpamWise, sans contenu de messages.
  • Exporter le diagnostic SpamWise enregistre ce même état dans un fichier.

Aperçu du message sélectionné et Corriger le message sélectionné nécessitent exactement un message sélectionné dans Mail, une configuration terminée et l’automatisation de Mail autorisée. Laissez leur UUID de la demande vide. Chaque résultat ou erreur indique l’UUID utilisé ; pour réessayer cette exécution sans la répéter, saisissez cet UUID.

Pour connaître l’état de SpamWise sans créer de raccourci, utilisez le raccourci État du filtrage ou demandez à Siri « Vérifier l’état de SpamWise ».

Corriger un message d’une touche

  1. Ouvrez l’app Raccourcis et créez un raccourci.
  2. Ajoutez l’action Corriger le message sélectionné de SpamWise et réglez son Étiquette sur Légitime, Indésirables ou À vérifier.
  3. Ouvrez Détails du raccourci, choisissez Ajouter un raccourci clavier, puis appuyez sur les touches voulues, par exemple Contrôle + Option + J.

Créez un raccourci pour chaque étiquette que vous utilisez. Les touches fonctionnent dans toutes les apps, y compris Mail, et corrigent le message sélectionné dans Mail.
