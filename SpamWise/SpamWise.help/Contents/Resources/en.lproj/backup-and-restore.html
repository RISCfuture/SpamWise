Backup and restore

A backup holds your rules, filtering settings, mail choices and additional instructions, address exceptions, corrections and learning, encrypted with a recovery key. Keys, passwords and spending stay on this Mac.

Export a backup

  1. Choose File → Export Backup…, or open Backup and restore in Settings → Advanced.
  2. Choose Create Recovery Key. Choose Copy or Save to File… and keep the key somewhere safe, apart from the backup. A copied key is cleared from the clipboard after a minute.
  3. To include message text SpamWise has kept, turn on Include saved message text. Without it, the backup also leaves out the short excerpts of your corrections.
  4. Choose Export Backup…, confirm that you saved the key, and choose where to save the backup.

SpamWise can’t recover a lost recovery key, and a backup can’t be restored without it.

Restore a backup

  1. Choose File → Restore from Backup…, open Backup and restore in Settings → Advanced, or double-click the backup file in Finder.
  2. Enter the backup’s Recovery key and choose Restore Backup….
  3. Choose the backup file, then choose Restore and Pause Filtering.

Your rules, filtering settings, mail choices and additional instructions, address exceptions, corrections and learning are replaced with the backup’s. A backup from an earlier version of SpamWise may not hold address exceptions or the learning switches; this Mac keeps its own for those. Restoring doesn’t change Keep text of reviewed messages: while it’s off, the backup’s message text and correction excerpts aren’t restored.

Filtering pauses and dry run turns on. In Settings → Accounts, choose Check Mail Connection, or Check Connection for an IMAP account. Then resume filtering and turn off dry run when you’re ready. On a new Mac, enter your API keys and IMAP password again.

If SpamWise can’t read its data

If SpamWise opens with “Some SpamWise data couldn’t be read”, it has set that data aside and keeps running with everything else; mail stays unchanged. Choose Save a Copy… to keep the set-aside data, then restore a backup, or choose Keep Current Settings… to continue without it.
