How decisions are made

SpamWise checks each message against the following, in order. The first one that applies decides the message.

  1. Sender rules. A rule for the sender’s email address wins over a rule for its domain. A Block rule always applies. An Allow rule applies only when the account has a trusted mail server that confirms the message came from the sender’s domain. Otherwise it only makes Junk less likely.
  2. Content rules. Rules that match a message’s subject, body or headers. When several match, the newest one decides. See Content rules.
  3. People you know. Senders in Contacts, people you’ve written to, and stores that sent you order confirmations go to Inbox. Like Allow rules, this requires a trusted mail server that confirms the sender; otherwise it only makes Junk less likely.
  4. Campaigns you marked as Junk. When Recognize campaigns you marked as Junk is on in Settings → Advanced, a message that closely matches one is marked Review.
  5. Your provider. Everything else goes to the provider you chose in Settings → Classifier, with your mail policy and a few of your similar corrections. It answers Good, Review or Junk, with a confidence. A Junk answer below the confidence your filtering strength requires becomes Review.

If part of a message can’t be read reliably, a Good answer becomes Review, so you can look at it yourself.

Trust an account’s mail server

A sender’s address can be forged. So Allow rules and people you know send mail straight to Inbox only when SpamWise trusts the server that receives the account’s mail and that server confirms the sender. In Settings → Accounts, each account shows its Trusted mail server.

  • Once SpamWise has detected the account’s server from new mail, choose Trust Detected Server.
  • Or choose Enter Server… and enter the server named first in the account’s Authentication-Results headers.

Choose Stop Trusting to go back. Block rules and content rules don’t need a trusted server.

Describe what you want to receive

In Settings → Policy, write in your own words what mail you want and what you don’t, under Your mail policy. Your provider reads it with every message it classifies. Changes are saved as you type. Choose Reset to default to start again from SpamWise’s policy.

What SpamWise doesn’t hold against a message

Missing permissions, failed lookups and unknown history never count as signs of spam. SpamWise never loads remote images or opens links in messages. When a message can’t be classified, for example because the provider is unavailable, it stays where it is and Activity shows it as Unclassified.
