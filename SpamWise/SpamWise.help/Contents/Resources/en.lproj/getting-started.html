Getting started

SpamWise classifies messages as Inbox, Review, or Junk. It never deletes messages or moves them to Trash. Start in dry run to see intended decisions without requesting mail actions.

Complete the four setup steps: privacy, optional Anthropic key verification, Mail and optional Contacts access, then an optional dry run on 20 recent Inbox messages. You can finish offline and return to Settings.

Provider selection is explicit. Claude verification uses a synthetic message and stores a successful key in Keychain. OpenAI, Gemini, Apple on-device, and Private Cloud Compute have separate availability requirements. SpamWise never silently substitutes another provider or model. Advanced learning and evidence features start disabled.

Allow Automation when asked. To validate Apple Mail actions, select one disposable Inbox message whose subject begins [SpamWise Probe]. Prefer a message sent from another account. The probe moves it to Junk, restores Inbox, and applies an orange flag, checking the location after 30 seconds per move. Inspect the restored message before disabling dry run. Repeat for each account.

For the Mail-rule route, copy the bundled script to ~/Library/Application Scripts/com.apple.mail/ and select it in a Mail rule. Keep SpamWise running. MailKit remains a separate dry-run route. IMAP requires its own TLS configuration, credentials, and read-only validation before any action is enabled.
