Getting started

SpamWise classifies messages as Inbox, Review, or Junk. It never deletes messages or moves them to Trash. Start in dry run to see intended decisions without requesting mail actions.

Complete the four setup steps: privacy, optional Anthropic key verification, Mail and optional Contacts access, then an optional dry run on 20 recent Inbox messages. You can finish offline and return to Settings.

Provider selection is explicit. Claude verification uses a synthetic message and stores a successful key in Keychain. OpenAI, Gemini, Apple on-device, and Private Cloud Compute have separate availability requirements. SpamWise never silently substitutes another provider or model. Advanced learning and evidence features start disabled.

Allow Automation when asked. Dry-run checks start as soon as Mail Automation is allowed. Use Check Mail connection in Settings → Accounts so SpamWise can confirm, without changing any mail, that each account’s Inbox and Junk mailboxes resolve uniquely. Dry run stays on until you turn it off in General and confirm; only accounts with validated mailboxes are then filtered. SpamWise checks every move afterward. If Mail doesn’t confirm a move, SpamWise doesn’t retry or reverse it, and Activity shows the failure so you can check the message in Mail. An optional move test with a message whose subject begins [SpamWise Probe] is in Settings → Advanced.

For the Mail-rule route, copy the bundled script to ~/Library/Application Scripts/com.apple.mail/ and select it in a Mail rule. When the rule runs, SpamWise checks each included account’s newest Inbox mail first; it also checks every minute while running. Keep SpamWise running. The Mail extension is an optional dry-run preview chosen in Settings → Accounts. It can’t tell which account a message belongs to, so it previews mail only when all accounts are included, and automatic Inbox checks stay off while it is chosen. IMAP requires its own TLS configuration, credentials, and read-only validation before any action is enabled.

Automatic filtering considers only mail received after setup finishes or, for an account added or included later, after SpamWise first checks it. To filter older Inbox mail, turn dry run off, open Settings → Accounts → Accounts and scan health, preview a page of older mail, review the decisions in Activity, then apply them. Mail previewed in dry run keeps its recorded decision when dry run is turned off.
