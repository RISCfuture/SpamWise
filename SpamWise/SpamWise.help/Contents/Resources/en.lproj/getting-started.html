Getting started

SpamWise classifies Apple Mail messages as Inbox, Review, or Junk. It never deletes mail or moves anything to Trash. Start in dry run: Activity shows intended decisions without requesting mail actions.

Complete the four setup steps: read the privacy summary, optionally verify an Anthropic API key, connect Mail and optionally Contacts, then try a dry run on 20 recent Inbox messages. You can finish offline and return to Settings.

Verify sends a synthetic message to Claude Haiku 5.5, then saves the key only in Keychain. Haiku 5.5 must be available to your account; SpamWise does not substitute a different model.

Allow Automation for SpamWise when asked. Mail → Settings → Extensions enables the incoming MailKit dry-run route. Import Inbox and Sent history to provide partial relationship evidence.

Actions require an explicit disposable-message test for each account. Select an Inbox message whose subject begins [SpamWise Probe]. The test moves it to Junk, back to Inbox, and applies an orange flag. If it cannot return, restore it manually. Only then can General settings disable dry run.

Use the bundled rule script for incoming Apple Events actions: Show Mail rule script in Finder, copy it to ~/Library/Application Scripts/com.apple.mail/, and choose it in a Mail rule. Keep SpamWise running. It also checks a bounded recent Inbox window once a minute. The rule URL contains no message data.
