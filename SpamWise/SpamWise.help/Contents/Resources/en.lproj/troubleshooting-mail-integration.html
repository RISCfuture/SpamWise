Troubleshooting Mail integration

SpamWise isn’t allowed to control Mail

SpamWise reads and moves mail through Mail, which needs your permission. If Settings → Accounts says “SpamWise isn’t allowed to control Mail, so it can’t check or move mail”:

  1. Choose Open Automation Settings. You can also open System Settings → Privacy & Security → Automation.
  2. Under SpamWise, turn on Mail.
  3. In SpamWise, choose Check Mail Connection.

SpamWise doesn’t need Full Disk Access, so don’t grant it or turn off macOS security features. If Settings asks you to open Mail, open it; SpamWise checks your accounts once Mail is running.

Contacts access is optional. To allow it, turn on SpamWise in System Settings → Privacy & Security → Contacts, then choose Connect Contacts in Settings → Accounts.

Mail wasn’t moved

Select the message in Activity and check its Outcome in the inspector. The SpamWise menu bar menu and the bottom of the Activity window also say what is holding filtering back. Common causes:

  • Dry run is on. The Outcome is Dry run. Choose Start Filtering…, or turn off “Dry run — do not change mail” in Settings → General. SpamWise then acts on the mail it checked during the dry run that’s still in your Inbox.
  • SpamWise hasn’t found the account’s Inbox and Junk mailboxes. The account says “SpamWise won’t move this account’s mail until it finds the Inbox and Junk mailboxes.” Choose Check Mail Connection, or open Mailboxes and Details under the account and choose Check Mailboxes. See Set up the account’s Junk mailbox.
  • Filtering is paused. The Outcome is Paused. Choose Filtering → Resume Filtering.
  • The account isn’t included. Turn on Filter this account under the account in Settings → Accounts. Filtering starts with mail that arrives from then on.
  • There’s no API key, or mail sharing is off. The Verdict is Unclassified. In Settings → Provider, add the key under API key and turn on “Allow mail context to be sent to provider”. Saving the key checks the waiting mail again automatically. To check one message right away, select it and choose Classify Again.
  • The monthly spending limit was reached. Raise the limit under Usage and spending in Settings → Provider, or wait until next month.
  • The message has no Message-ID. The inspector says “The message has no Message-ID, so SpamWise doesn’t move it automatically and left it in place.” You can still correct it in Activity, or move it in Mail yourself.
  • The mail arrived before filtering started. Older mail isn’t sorted automatically; see Sort older mail.
  • Mail isn’t running, or the Mac is offline. Checks resume when Mail opens or the connection returns.
  • The verdict is Good or Review. Good mail stays in Inbox, and Review mail stays in Inbox with its orange mark.

Set up the account’s Junk mailbox

SpamWise moves mail only in accounts where Mail shows exactly one Inbox and one Junk mailbox. If the account says that Mail hasn’t set a Junk mailbox:

  1. In Mail, select the account’s junk folder in the sidebar. If the account has none, create one with Mailbox → New Mailbox, choosing the account as its location.
  2. Choose Mailbox → Use This Mailbox For → Junk.
  3. In SpamWise, open Mailboxes and Details under the account in Settings → Accounts, and choose Check Mailboxes.

If the account says that Mail shows more than one Junk mailbox, keep the Junk role on one folder only: in Mail, select the folder you want to use, choose Mailbox → Use This Mailbox For → Junk, then choose Check Mailboxes. If Mail still shows another Junk mailbox for the account, its server may report several; ask your mail provider. With an IMAP connection, the server itself must mark one folder as its Junk folder; ask your mail provider if Check Connection can’t find it.

Use Gmail’s Spam as the Junk mailbox

Gmail keeps spam in its own Spam mailbox, in the [Gmail] folder ([Google Mail] in some countries). When Mail uses a Gmail label instead, such as a Junk label Mail created, SpamWise still moves junk into that label, but Gmail’s own spam filter doesn’t learn from it, and Gmail on the web and your other devices don’t treat the mail as spam. Setup and the account in Settings → Accounts then say that Mail uses a Gmail label as Junk instead of Gmail’s Spam. To use Gmail’s Spam:

  1. In Mail, open the account’s [Gmail] folder in the sidebar and select Spam.
  2. Choose Mailbox → Use This Mailbox For → Junk.
  3. In SpamWise, open Mailboxes and Details under the account in Settings → Accounts, and choose Check Mailboxes. Junk should show [Gmail]/Spam.

A label you created yourself isn’t Gmail’s Spam, even when it’s named Spam. If the [Gmail] folder has no Spam mailbox, Gmail is hiding it from Mail: on the Gmail website, open Settings → See all settings → Labels and turn on Show in IMAP for Spam. Mail shows it the next time it checks the account. Messages already in the old label stay there.

Mail marked or moved a message itself

If a message has Mail’s junk mark, or is in Junk but Activity doesn’t show SpamWise moving it, Mail’s own Junk Mail filter or your mail server did it. In Review Junk, SpamWise says “SpamWise didn’t put this message in Junk. Another filter or the mail server did.” To let SpamWise do the sorting, turn off Mail’s filter; see Mail’s own Junk Mail filter. Taking such a message out of Junk doesn’t teach SpamWise anything; to allow its sender, choose Mark as Good and Restore in Review Junk.

Restore a message

SpamWise never deletes mail. Anything it moved is in the account’s Junk mailbox.

  • In Activity, select the message and choose Filtering → Mark as Good. SpamWise moves it to Inbox and allows its sender.
  • Or choose Filtering → Review Junk, choose the account, select the message and choose Mark as Good and Restore. See Reviewing Junk.
  • Or move the message back to Inbox in Mail, or choose Not Junk. Once dry run is off, SpamWise treats that as marking it Good the next time it checks your Inbox, and allows the sender. It doesn’t if you take the message out within about 30 seconds of the move; see Take a message out of Junk in Mail.

Undo Latest Correction… restores rules and learning, but doesn’t move mail.

Messages aren’t classified

  • “No API key for provider”: add one under API key in Settings → Provider.
  • Apple on-device needs Apple Intelligence. Turn it on in System Settings → Apple Intelligence & Siri, or choose another provider.
  • “Mail isn’t classified while this Mac is kept local and a network provider is selected”: choose Apple on-device as the Provider, or turn off Keep filtering on this Mac.
  • When the provider is busy, unreachable or times out, messages stay where they are. Select one and choose Classify Again later. SpamWise never switches to another provider on its own.

Some mail couldn’t be checked

When Activity or the menu bar menu says “Some mail couldn’t be checked — see Settings → Accounts”, each account’s Status in Settings → Accounts shows the problem. A message Mail can’t load stays where it is and is tried again later, and SpamWise keeps checking the messages after it. Keep SpamWise and Mail open.

Check new mail sooner

SpamWise checks your Inbox every minute. To check new mail as soon as it arrives, add a Mail rule that runs the SpamWise script:

  1. In Settings → Accounts, under New mail, choose Show Script in Finder.
  2. Copy the selected script to the folder ~/Library/Application Scripts/com.apple.mail. To open the folder, choose Go → Go to Folder in Finder.
  3. In Mail, choose Mail → Settings, click Rules, then Add Rule. Set the condition to Every Message and the action to Run AppleScript, then choose the SpamWise script.

The rule checks new mail in the background, without bringing SpamWise forward. You don’t need to turn on SpamWise in Mail’s extension settings.
