Troubleshooting Mail integration

SpamWise isn’t allowed to control Mail

SpamWise reads and moves mail through Mail, which needs your permission. If Settings → Accounts says “SpamWise isn’t allowed to control Mail, so it can’t check or move mail”:

  1. Choose Open Automation Settings. You can also open System Settings → Privacy & Security → Automation.
  2. Under SpamWise, turn on Mail.
  3. In SpamWise, choose Check Mail Connection.

SpamWise doesn’t need Full Disk Access, so don’t grant it or turn off macOS security features. If Settings asks you to open Mail, open it; SpamWise checks your accounts once Mail is running.

Contacts access is optional. To allow it, turn on SpamWise in System Settings → Privacy & Security → Contacts, then choose Connect Contacts in Settings → Accounts.

Mail wasn’t moved

Select the message in Activity and check its Outcome in the inspector. The SpamWise menu-bar menu and the bottom of the Activity window also say what is holding filtering back. Common causes:

  • Dry run is on. The Outcome is Dry run. Turn off “Dry run — do not change mail” in Settings → General. SpamWise then acts on the mail it checked during the dry run that’s still in your Inbox.
  • SpamWise hasn’t found the account’s Inbox and Junk mailboxes. The account says “SpamWise won’t move this account’s mail until it finds the Inbox and Junk mailboxes.” Choose Check Mail Connection, or open Advanced under the account and choose Check Mailboxes. Mail must show exactly one Inbox and one Junk mailbox for the account.
  • Filtering is paused. The Outcome is Paused. Choose Filtering → Resume Filtering.
  • The account isn’t included. Turn on Filter this account under the account in Settings → Accounts. Filtering starts with mail that arrives from then on.
  • There’s no API key, or mail sharing is off. The Verdict is Unclassified. In Settings → Classifier, add the key under API key and turn on “Allow mail context to be sent to provider”. Then choose Classify Again.
  • The monthly spending limit was reached. Raise the limit under Usage and spending in Settings → Classifier, or wait until next month.
  • The mail arrived before filtering started. Older mail isn’t sorted automatically; see Sort older mail.
  • Mail isn’t running, or the Mac is offline. Checks resume when Mail opens or the connection returns.
  • The verdict is Good or Review. Good mail stays in Inbox, and Review mail stays in Inbox with its orange mark.

Restore a message

SpamWise never deletes mail. Anything it moved is in the account’s Junk mailbox.

  • In Activity, select the message and choose Filtering → Mark as Good. SpamWise moves it to Inbox and allows its sender.
  • Or choose Filtering → Review Junk, choose the account, select the message and choose Mark as Good and Restore. See Reviewing Junk.
  • If you move the message to Inbox in Mail yourself, also mark it as Good in Activity so SpamWise allows the sender next time.

Undo latest correction… restores rules and learning, but doesn’t move mail.

Messages aren’t classified

  • “No API key for provider”: add one under API key in Settings → Classifier.
  • Apple on-device needs Apple Intelligence. Turn it on in System Settings → Apple Intelligence & Siri, or choose another provider.
  • “Mail isn’t classified while this Mac is kept local and a network provider is selected”: choose Apple on-device as the Provider, or turn off Keep filtering on this Mac.
  • When the provider is busy, unreachable or times out, messages stay where they are. Select one and choose Classify Again later. SpamWise never switches to another provider on its own.

Some mail couldn’t be checked

When Activity or the menu-bar menu says “Some mail couldn’t be checked — see Settings → Accounts”, each account’s Status in Settings → Accounts shows the problem. A message Mail can’t load stays where it is and is tried again later, and SpamWise keeps checking the messages after it. Keep SpamWise and Mail open.

Check new mail sooner

SpamWise checks your Inbox every minute. To check new mail as soon as it arrives, add a Mail rule that runs the SpamWise script:

  1. In Settings → Accounts, under New mail, choose Show Script in Finder.
  2. Copy the selected script to the folder ~/Library/Application Scripts/com.apple.mail. To open the folder, choose Go → Go to Folder in Finder.
  3. In Mail, choose Mail → Settings, click Rules, then Add Rule. Set the condition to Every Message and the action to Run AppleScript, then choose the SpamWise script.

You don’t need to turn on SpamWise in Mail’s extension settings.

Test moving a message

To check that SpamWise can move mail in an account, send yourself a message whose subject begins “[SpamWise Probe]”. Select it in Mail’s Inbox, then open Diagnostics in Settings → Advanced and choose Test selected message. SpamWise moves it to Junk and back, then flags it orange. Dry run isn’t changed.
