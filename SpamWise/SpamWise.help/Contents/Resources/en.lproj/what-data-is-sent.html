What data is sent

The selected cloud provider receives bounded message text, subject, sender and link-domain evidence, your preferences, and quoted correction examples when local gates do not decide the message. These fields may contain personal information. The default context includes up to 40 corrections and about 1,500 body tokens, estimated from characters.

Apple on-device classification runs locally when supported. Private Cloud Compute uses Apple’s remote infrastructure and requires its managed entitlement. OpenAI and Gemini require their own keys. Selecting a provider is explicit consent to use that provider; unavailable providers fail without fallback.

RDAP reveals the sender’s domain to registration services. Optional DNS or URI reputation checks reveal their configured lookup identifiers to the chosen service and resolver; enable them only under that service’s terms. Local Rspamd receives bounded message content. Local OCR reads embedded images without downloading remote content.

API keys and IMAP passwords belong in Keychain. SpamWise does not inspect Mail databases or request Full Disk Access. Apple Events requires Automation permission; IMAP uses explicitly configured TLS credentials rather than borrowing Mail’s account secrets.

Local storage contains settings, rules, correction quotations, derived learning tokens and signatures, explanations, history indexes, and bounded retries with shortened text. Retaining reviewed message content for labeled export is optional. Exports and caches can contain private mail. The weekly Review digest stays local and sends no email.

Usage counts are measured when available; costs remain estimates. Provider-specific pricing and cache accounting can differ. The configured paid-call ceiling starts at $150. Each paid call reserves a conservative upper bound before it starts; failed or uncertain calls keep their reservations. Calls stop before exceeding the ceiling, so reserved commitments can exceed estimated actual charges.
