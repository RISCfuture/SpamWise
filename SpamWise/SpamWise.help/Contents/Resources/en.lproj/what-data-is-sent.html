What data is sent

The selected cloud provider receives bounded message text, subject, sender and link-domain evidence, your preferences, and quoted correction examples when local gates do not decide the message. These fields may contain personal information. The default context includes up to 40 corrections and about 1,500 body tokens, estimated from characters.

Apple on-device classification runs locally when supported. Private Cloud Compute uses Apple’s remote infrastructure and requires its managed entitlement. OpenAI and Gemini require their own keys. Grant mail-sharing permission separately for each cloud provider in Accounts settings. Revoke it to stop future requests; already sent requests cannot be recalled. Unavailable providers fail without fallback.

Optional RDAP lookups, disabled by default, reveal the sender’s domain to registration services. Optional DNS or URI reputation checks reveal their configured lookup identifiers to the chosen service and resolver; enable them only under that service’s terms. Local Rspamd receives bounded message content. Local OCR reads embedded images without downloading remote content.

API keys and IMAP passwords belong in Keychain. SpamWise does not inspect Mail databases or request Full Disk Access. Apple Events requires Automation permission; IMAP uses explicitly configured TLS credentials rather than borrowing Mail’s account secrets.

Local storage contains settings, rules, correction quotations, derived learning tokens and signatures, explanations, history indexes, and bounded retries with shortened text. Retaining reviewed message content for labeled export is optional. Exports and caches can contain private mail. The weekly Review digest stays local and sends no email.

Usage counts are measured when available; costs remain estimates. Provider-specific pricing and cache accounting can differ. In Accounts settings, under Usage and spending, you can set an optional monthly spending limit. It is off by default and starts over each calendar month. While a paid request runs, it counts its largest possible cost; when it finishes, its measured cost replaces that amount. A request stopped before it was sent, or rejected for a missing or invalid key, a provider rate limit or an oversized message, counts nothing; any other failed request keeps its largest possible cost. When the next request would exceed the limit, SpamWise stops sending mail to the provider, leaves that mail unchanged, and shows that the limit was reached. Later Inbox scans classify that mail once requests fit under the limit again.

Local mode blocks cloud classification and outbound RDAP, DNS and sidecar evidence; Mail.app may still synchronize accounts. Optional plain-text/HTML attachment extraction and image OCR run locally, but their extracted text can enter the bounded prompt sent to your explicitly selected cloud provider. PDF/Office content is not read. Notifications contain counts only, with no subjects or senders.
