What data is sent

Anthropic receives message context only when local gates do not decide it: sender and link-domain evidence, subject, shortened body text, your policy, and bounded recent correction examples. Those fields can contain personal information. The default is 40 examples and approximately 1,500 body tokens; the body budget is a character estimate.

Optional RDAP domain-age discovery sends the sender’s domain to IANA bootstrap and the discovered registration service. No body, subject, or API key is sent to RDAP. Results and unavailable lookups are cached.

SpamWise does not fetch message links or remote images. It does not inspect Mail databases and does not ask for Full Disk Access. Mail source and history are read through Apple Events after Automation permission; Contacts is optional.

The API key is stored only in the shared Keychain. App Group storage contains settings, learned rules, bounded correction examples, decision explanations, history indexes, and a bounded retry queue containing shortened message text. The Activity log retains 5,000 records; action claims persist to prevent duplicate actions.

Token counts are measured when provided by the backend. Dollar costs are estimates because cache-write premiums are not separately exposed. Evaluation exports, reports, and response caches are separate local files that may contain private mail or reasons; choose their locations carefully.
