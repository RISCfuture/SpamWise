Sender and content rules

Open Settings → Rules, then choose Sender Rules or Content Rules at the top.

Sender rules

A sender rule always allows or blocks mail from an email address or an entire domain. Your corrections create sender rules; you can also manage them yourself.

  • To add one, choose Add Rule…, choose what it Applies to (Email address or Entire domain), enter the address or domain, choose Allow or Block, then choose Save.
  • To change a rule’s action, select it and choose Edit…. To delete rules, select them and choose Remove…. Mail already filtered stays where it is.
  • To copy rules to another Mac, choose Transfer Rules → Export Rules…, then Import Rules… on the other Mac. Before it saves anything, SpamWise lists the new rules and the rules that change, and names any Block rules that would become Allow rules; choose Import Rules to save them. Imported rules replace rules for the same address or domain. Exports contain no messages or passwords.

A rule for an address wins over a rule for its domain. Allow rules decide only mail SpamWise can verify; see Trust an account’s mail server.

When you correct several senders at a domain the same way, Settings → Advanced suggests a rule under Suggested domain rules. Choose Allow Domain or Block Domain to add it.

Content rules

A content rule allows or blocks mail by what it contains. Content rules apply after sender rules.

  1. Under Content Rules, choose Add Rule….
  2. Choose the Field to check: Subject, Body, List-ID, Recipients, Reply-To, Content type, Attachment names or Attachment types.
  3. Choose how to Match it: Contains, Equals or Regular expression, and enter the Expression. Matching ignores capitalization.
  4. Choose Allow or Block, and add Notes to remind yourself why.
  5. To try the rule, select a message in Mail and choose Test with Message Selected in Mail.
  6. Choose Save.

When several content rules match, the newest one decides. A Block rule always applies. An Allow rule, like a sender Allow rule, decides only mail SpamWise can verify; otherwise it only makes Junk less likely, and a matching Block rule below it still applies. To turn a rule off without removing it, turn off its Use this rule switch. Matches counts the messages each rule decided. Couldn’t Check counts messages a rule couldn’t be checked against, for example because its expression is invalid; a rule that takes too long to check doesn’t match. To copy content rules to another Mac, use Transfer Rules → Export Content Rules… and Import Content Rules….
