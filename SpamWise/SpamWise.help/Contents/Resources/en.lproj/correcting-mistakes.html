Correcting mistakes

Select a row in Activity and choose Mark as Good or Mark as Junk. SpamWise immediately saves an address rule and a bounded example, then attempts the supported Inbox or Junk action when the account is validated and dry run and pause are off.

The latest correction replaces the prior rule for that same address. An address correction does not change other senders on the domain. Use Correct entire domain only when you explicitly want all senders on that registrable domain affected.

A mail action failure does not undo the learned correction. Read the separate outcome and action error in the detail pane. You can move the message manually in Mail and keep the saved learning.

Corrections invalidate queued classification retries and supersede in-flight old verdicts before dispatch. An external action already requested cannot be recalled. Pause or dry run prevents new requests but cannot reverse an action already delivered to Mail.

The Advanced settings list learned rules. Rule editing and import/export are deferred; use an opposite correction to replace a rule at the same scope.
