Correcting mistakes

Correct a message in Activity

Select the message in Activity, then choose one of these from the Filtering menu, or Control-click the message:

  • Mark as Good (Option-Command-G) moves the message to Inbox.
  • Mark as Junk (Option-Command-J) moves it to the account’s Junk mailbox.
  • Mark for Review (Option-Command-R) returns it to Inbox with the Review mark.

You can also use the Good, Junk and Review buttons under Correct this decision in the inspector. SpamWise saves your correction first, then asks Mail to move the message. If the move fails, the correction stays saved, and the inspector’s Outcome shows what happened in Mail. A message without a sender address can’t be corrected; move it in Mail instead.

What a correction remembers

  • Mark as Good creates an Allow rule for the sender’s address, and Mark as Junk creates a Block rule. A new correction replaces the earlier rule for that address.
  • Mark for Review removes the sender’s address rule. A rule for the sender’s domain stays in force.
  • Each correction is also kept as an example for your provider and for learning. See Reviewed messages and learning.

If SpamWise couldn’t verify that a message really came from its sender, it asks before blocking, because blocking a forged address also sends the real sender’s mail to Junk. Choose Block Sender Anyway, Mark as Scam to move the message to Junk without a rule for the sender, or Cancel. If a domain rule still decides the sender’s mail against your correction, SpamWise says so; choose Keep Rule or Remove Rule.

When the message is a kind of mail you can choose for in Mail Choices, such as a store promotion, SpamWise may ask whether to do the same for all of that kind. Choose Just This Sender, or Keep All in Inbox, Flag All for Review or Move All to Junk.

Correct a whole domain

To allow or block every sender at a domain, choose Correct Entire Domain… in the inspector, then Allow This Domain or Block This Domain. For domains many people share, such as large mail providers, SpamWise asks first, because the rule would also apply to unrelated people. A rule for an address still wins over a rule for its domain.

Correct messages selected in Mail

Select one or more messages in Mail. Then, in the SpamWise menu bar menu, under Selected messages in Mail, choose Mark as Good, Mark as Junk or Mark for Review, or choose Correct Senders’ Domains → Allow Senders’ Domains or Block Senders’ Domains. The menu shows progress; choose Show Correction Results… for details. If some senders can’t be verified, choose Confirm Unverified Senders…, then Block All or Skip Unverified Senders. These corrections also remove SpamWise’s orange Review mark.

The menu bar commands have no keyboard shortcuts. To correct the message selected in Mail with a key:

  1. Open the Shortcuts app and create a shortcut.
  2. Add SpamWise’s Correct Selected Mail action and set its Label to Good, Junk or Review.
  3. Open Shortcut Details, choose Add Keyboard Shortcut and press the keys you want, such as Control-Option-J.

Make one shortcut for each label you use. The keys work in any app, including Mail, and correct the one message selected in Mail.

Take a message out of Junk in Mail

If SpamWise moved a message to Junk and you move it back to Inbox in Mail, or choose Not Junk, SpamWise treats it as marked Good the next time it checks your Inbox: it allows the sender and learns from the message. This works the same with an IMAP connection and any mail app. It doesn’t happen:

  • during a dry run;
  • when you take the message out of Junk within about 30 seconds of the move. SpamWise checks each Junk move again after about 30 seconds and learns only from moves that were still in place. If SpamWise quit before that check, it learns nothing from that message;
  • for mail SpamWise didn’t move to Junk, or that you already corrected.

This correction never moves mail. If you’ve moved the message again by the time SpamWise looks, it stays where you put it, and Activity shows that the correction’s mail action didn’t happen.

Undo a correction

To undo your latest correction’s rules and learning, select that message and choose Undo Latest Correction… in the inspector, then Undo Rules and Learning. When you corrected several messages selected in Mail at once, the undo covers all of them. Mail doesn’t move, so move the message yourself if needed. Undo isn’t available once you’ve made later changes, including saving the API key of the provider you use.

Classify a message again

If a message wasn’t classified, for example because your provider was unavailable, select it and choose Filtering → Classify Again, or Classify Again in the inspector. Dry run and Pause still apply.
