Correcting mistakes

Select an Activity row and choose Mark as Good or Mark as Junk. SpamWise saves an address rule and a bounded correction before attempting the supported mail action. The latest correction replaces the prior rule for that address. A failed mail action does not undo the saved correction.

Mark as Review records uncertainty and removes the address rule for that sender. It does not remove an explicit domain rule. Review is a separate label, not a Good or Junk training example.

Use Correct entire domain only when you want all senders on that registrable domain affected. Address rules still take precedence. In Advanced settings, add, edit, remove, import, or export sender rules. Import validates the complete archive before merging and replaces matching address or domain scopes. Rule exports contain no message bodies or credentials.

Learning suggestions summarize repeated, noncontradictory corrections. Review the scope before applying a suggestion; it never changes policy automatically. An explicit Good correction suppresses matching learned Junk campaigns. Rules and trusted relationships remain authoritative.

Corrections invalidate queued retries and stale classifications before dispatch. An action already delivered to Mail or an IMAP server cannot be recalled. Inspect the separate outcome and action error, and restore the message manually if needed. Pause and dry run prevent new requests; they do not reverse earlier ones.

Enable local reviewed-content retention if you want to export a labeled calibration corpus later. Labels alone remain useful, but automatic mailbox placement is not a human-reviewed label. Statistical hold-out counts do not establish end-to-end calibration of rules, retrieval, or campaign matching.
