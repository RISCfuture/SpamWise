Correcting mistakes

Correct a message in Activity

Select the message in Activity, then choose one of these from the Filtering menu:

  • Mark as Good (Shift-Command-G) moves the message to Inbox.
  • Mark as Junk (Shift-Command-J) moves it to the account’s Junk mailbox.
  • Mark for Review (Shift-Command-R) returns it to Inbox with the Review mark.

You can also use the Good, Junk and Review buttons under Correct this decision in the inspector. SpamWise saves your correction first, then asks Mail to move the message. If the move fails, the correction stays saved, and the inspector’s Outcome shows what happened in Mail.

What a correction remembers

  • Mark as Good creates an Allow rule for the sender’s address, and Mark as Junk creates a Block rule. A new correction replaces the earlier rule for that address.
  • Mark for Review removes the sender’s address rule. A rule for the sender’s domain stays in force.
  • Each correction is also kept as an example for your provider and for learning. See Reviewed messages and learning.

If SpamWise couldn’t verify that a message really came from its sender, it asks before blocking, because blocking a forged address also sends the real sender’s mail to Junk. Choose Block Sender Anyway or Cancel. If a domain rule still decides the sender’s mail against your correction, SpamWise says so; choose Keep Rule or Remove Rule.

Correct a whole domain

To allow or block every sender at a domain, choose Correct entire domain… in the inspector, then Allow this domain or Block this domain. For domains many people share, such as large mail providers, SpamWise asks first, because the rule would also apply to unrelated people. A rule for an address still wins over a rule for its domain.

Correct messages selected in Mail

Select one or more messages in Mail. Then, in the SpamWise menu-bar menu, under Selected messages in Mail, choose Mark as Good, Mark as Junk or Mark for Review, or choose Correct Senders’ Domains → Allow Senders’ Domains or Block Senders’ Domains. The menu shows progress; choose Show Correction Results… for details. If some senders can’t be verified, choose Confirm Unverified Senders… to decide whether to block them.

The menu-bar commands have no keyboard shortcuts. To correct the message selected in Mail with a key:

  1. Open the Shortcuts app and create a shortcut.
  2. Add SpamWise’s Correct Selected Mail action and set its Label to Good, Junk or Review.
  3. Open Shortcut Details, choose Add Keyboard Shortcut and press the keys you want, such as Control-Option-J.

Make one shortcut for each label you use. The keys work in any app, including Mail, and correct the one message selected in Mail.

Undo a correction

To undo your latest correction’s rules and learning, choose Undo latest correction… in the inspector, then Undo rules and learning. Mail doesn’t move, so move the message yourself if needed. Undo isn’t available once you’ve made later changes, including saving the API key of the provider you use.

Classify a message again

If a message wasn’t classified, for example because your provider was unavailable, select it and choose Filtering → Classify Again, or Classify Again in the inspector. Dry run and Pause still apply.
