Updating and removing SpamWise

Keep only one copy of SpamWise on your Mac. The App Store version and the downloaded version share their settings, so install one or the other.

Update SpamWise

If you got SpamWise from the App Store, it updates through the App Store like your other apps.

If you downloaded SpamWise, it checks for new versions itself. In Settings → General, under App updates:

  • Check for updates sets how often it checks: Hourly, Daily, Weekly or Never.
  • Include prerelease versions also offers test versions before their release.
  • Check Now checks right away, as does SpamWise → Check for Updates…. Reset Skipped Versions offers versions you chose to skip again.

When you accept an update, SpamWise downloads it as a disk image. Before you install it, you can export a backup; see Export a backup. Then quit SpamWise, open the disk image, drag SpamWise to the Applications folder to replace the old copy, and open SpamWise again. Your settings, rules and learning stay as they were.

Stop SpamWise from opening at login

Turn off Open SpamWise at login in Settings → General. You can also check the login items in System Settings → General. SpamWise filters only while it’s open, so to stop filtering now, choose Quit SpamWise in its menu bar menu or SpamWise → Quit SpamWise.

Remove keys and passwords

SpamWise keeps your API keys, the Spamhaus query key and your IMAP password in Keychain. Removing the app alone leaves them there, so remove them first if you won’t use SpamWise again. In Settings → Accounts, under Keys and passwords:

  • To remove one, choose Remove next to it. To remove a provider’s API key, you can also choose Remove Key… in Settings → Provider.
  • To remove them all, choose Remove All SpamWise Keys and Passwords…, then Remove All.

Mail isn’t classified with a provider until you add its key again. To stop using an IMAP connection, see Connecting with IMAP.

Remove SpamWise from your Mac

  1. Remove your keys and passwords, as above, and turn off Open SpamWise at login.
  2. If you added the Mail rule that runs the SpamWise script, open Mail → Settings, click Rules, select the rule and click Remove. Then remove the SpamWise script from the folder ~/Library/Application Scripts/com.apple.mail.
  3. Quit SpamWise, then drag it from the Applications folder to the Trash.

Removing SpamWise doesn’t change your mail. Messages it moved to Junk stay there, and Review marks stay until you remove them in Mail. Your rules, corrections and learning stay on this Mac, so they’re back if you install SpamWise again.

To remove that data too, export a backup first if you might want it later. Then, in Finder, choose Go → Go to Folder and open ~/Library/Group Containers. Move the folder group.codes.tim.SpamWise to the Trash. Then open ~/Library/Containers and move the folders codes.tim.SpamWise and codes.tim.SpamWise.MailExtension to the Trash; Finder may show them as SpamWise. Don’t remove Mail’s folders.
