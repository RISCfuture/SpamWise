Shortcuts

SpamWise adds these actions to the Shortcuts app:

  • Preview Selected Mail classifies the message selected in Mail without moving it. It uses your provider and spending limit.
  • Correct Selected Mail corrects the message selected in Mail as Good, Junk or Review, like the commands in Activity. Pause, dry run and the account’s mailbox check still apply.
  • Get SpamWise Status returns SpamWise’s status, without message content.
  • Export SpamWise Diagnostics saves the same status as a file.

Preview Selected Mail and Correct Selected Mail need exactly one message selected in Mail, setup finished and Mail Automation allowed. Leave their Request UUID empty. Each result or error names the UUID it used; to retry that run without repeating it, enter that UUID.

For SpamWise’s status without building a shortcut, use the Filtering Status shortcut or ask Siri to “Check SpamWise status”.

Correct mail with a key

  1. Open the Shortcuts app and create a shortcut.
  2. Add SpamWise’s Correct Selected Mail action and set its Label to Good, Junk or Review.
  3. Open Shortcut Details, choose Add Keyboard Shortcut and press the keys you want, such as Control-Option-J.

Make one shortcut for each label you use. The keys work in any app, including Mail, and correct the one message selected in Mail.
