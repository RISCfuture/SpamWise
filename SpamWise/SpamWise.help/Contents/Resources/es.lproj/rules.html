Reglas de remitente y de contenido

Abre Ajustes → Reglas y elige Reglas de remitente o Reglas de contenido en la parte superior.

Reglas de remitente

Una regla de remitente siempre permite o bloquea el correo de una dirección o de todo un dominio. Tus correcciones crean reglas de remitente; también puedes gestionarlas tú.

  • Para añadir una, elige Añadir regla…, elige a qué Se aplica (Dirección de correo o Todo el dominio), escribe la dirección o el dominio, elige Permitir o Bloquear y después Guardar.
  • Para cambiar la acción de una regla, selecciónala y elige Editar…. Para eliminar reglas, selecciónalas y elige Eliminar…. El correo ya filtrado se queda donde está.
  • Para copiar las reglas a otro Mac, elige Transferir reglas → Exportar reglas… y después Importar reglas… en el otro Mac. Las reglas importadas sustituyen a las de la misma dirección o dominio. Las exportaciones no contienen mensajes ni contraseñas.

Una regla para una dirección prevalece sobre una regla para su dominio. Las reglas Permitir solo deciden el correo que SpamWise puede verificar; consulta Confiar en el servidor de correo de una cuenta.

Cuando corriges igual a varios remitentes de un dominio, Ajustes → Avanzado sugiere una regla en Reglas de dominio sugeridas. Elige Permitir dominio o Bloquear dominio para añadirla.

Reglas de contenido

Una regla de contenido permite o bloquea el correo según lo que contiene. Las reglas de contenido se aplican después de las reglas de remitente.

  1. En Reglas de contenido, elige Añadir regla….
  2. Elige el Campo que se comprueba: Asunto, Cuerpo, List-ID, Destinatarios, Reply-To, Tipo de contenido, Nombres de adjuntos o Tipos de adjuntos.
  3. Elige el tipo de Coincidencia: Contiene, Es igual a o Expresión regular, y escribe la Expresión. No se distingue entre mayúsculas y minúsculas.
  4. Elige Permitir o Bloquear, y añade Notas para recordar por qué.
  5. Para probar la regla, selecciona un mensaje en Mail y elige Probar con el mensaje seleccionado en Mail.
  6. Elige Guardar.

Si coinciden varias reglas de contenido, decide la más reciente. Usa el interruptor de una regla para desactivarla sin eliminarla. Coincidencias cuenta los mensajes que decidió cada regla. Omitidas cuenta los mensajes que una regla no pudo comprobar; una regla que tarda demasiado en comprobarse no coincide. Para copiar las reglas de contenido a otro Mac, usa Transferir reglas → Exportar reglas de contenido… e Importar reglas de contenido….
